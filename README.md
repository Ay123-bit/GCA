# 🛰️ Geo Compiler AI

## Enterprise Satellite Intelligence Platform

Geo Compiler AI is a deep learning based satellite intelligence platform that combines **CNN-based land cover classification, computer vision, NDVI vegetation analysis, GIS intelligence, and environmental AI recommendations** into a unified analytics dashboard.

The platform processes satellite images and provides AI-driven insights for land monitoring, vegetation assessment, and environmental analysis.

---

# 🚀 Features

## 🧠 Deep Learning Intelligence

* CNN-based satellite image classification
* Land cover prediction
* AI confidence scoring
* Model validation system

## 🔍 Computer Vision Engine

* Image feature extraction
* Edge detection
* Brightness analysis
* Contrast analysis
* Texture analysis
* Sharpness measurement

## 🌱 NDVI Vegetation Intelligence

* Vegetation health analysis
* NDVI score calculation
* Vegetation classification:

  * Healthy vegetation
  * Moderate vegetation
  * Poor vegetation
  * Water/Barren region

## 🗺️ GIS Intelligence

* GeoJSON boundary processing
* Spatial analysis
* Satellite location intelligence
* Interactive map visualization

## 🤖 Environmental AI Recommendation

AI-based recommendations for:

* Forest monitoring
* Land degradation analysis
* Vegetation assessment
* Hydrological analysis

## 📊 Reporting System

* AI intelligence report generation
* JSON export
* TXT export
* PDF report support
* System diagnostics

# ⚡ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Move into project directory:

```bash
cd Geo-Compiler-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

Start Streamlit dashboard:

```bash
streamlit run app.py
```

After running, open:

```
http://localhost:8501/
```
